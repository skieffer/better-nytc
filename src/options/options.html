BetterNYTC Extension Options

BetterNYTC can now improve other games besides the Crossword!

Control the new, optional features from this options page.

Config

A sun/moon toggle will be found to the top-right, just above the game area in the following games: Connections, Letter Boxed, Pips, Spelling Bee, Strands, Sudoku, and Tiles.

After activating/deactivating, you may need to reload the game page in order for the change to take effect.
